# Procm Rooms Examples

Load only the example relevant to the current task:

- [SDK messaging](sdk-messaging.md): connect clients, publish, and subscribe by exact topic or prefix.
- [Retained readiness](retained-readiness.md): coordinate initialization with `retain` and `waitFor`.
- [Structured logging](structured-logging.md): emit parseable logs and query merged room history.
- [Room operations](room-operations.md): use MCP and HTTP room/batch surfaces.
- [Electron integration](electron-integration.md): keep SDK access in main/preload boundaries.
- [Browser integration](browser-integration.md): load the single browser ESM bundle from a native module script.

For a runnable two-process application, see the repository [demo guide](../../../../demo/README.md).
