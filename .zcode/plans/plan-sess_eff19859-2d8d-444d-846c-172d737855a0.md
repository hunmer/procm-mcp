## Goal
Add `react-dev-inspector` to the `procm-mcp` dashboard so that in **dev mode** you can click a component in the browser and jump to its source file in your editor. In production the feature is completely stripped out.

The reference (`G:\agent_spaces\packages\web\src\components\layout\dev-inspector.tsx`) targets **Next.js + a custom HTTP server**, so it hand-rolls a webpack loader and server middleware. This dashboard is **Vite 6**, so we use the official `@react-dev-inspector/vite-plugin` instead — one plugin handles both source-attribute injection *and* the editor-launch server. The component itself is ported over almost verbatim.

- Add the `'@react-dev-inspector/babel-plugin'` to the existing `react()` call via its `babel.plugins` option, so JSX nodes get `data-inspector-relative-path` / `-line` / `-column` attributes in dev.

Resulting plugin section:
```ts
plugins: [
  react({
    babel: { plugins: ["@react-dev-inspector/babel-plugin"] },
  }),
  tailwindcss(),
  inspectorServer(),

```
**Why no proxy/routing work:** the dev-server proxy forwards only `/api`, `/mcp`, `/assets`, `/ws`. The inspector middleware answers on `/__open-stack-frame-in-editor`, which none of those match, so it runs on the Vite dev server untouched. `inspectorServer()` is dev-only by design, so production builds (`vite build`) are unaffected.

## How it works end-to-end (dev only)
1. **Build (dev):** the babel plugin injects `data-inspector-*` attributes on JSX DOM nodes; `inspectorServer()` registers the `/__open-stack-frame-in-editor` middleware on the Vite dev server.
2. **Browser:** press `Ctrl+Shift+Alt+C` (Win/Linux) or click the floating mouse-pointer button (bottom-right, max z-index) → hover elements to highlight → click → `gotoServerEditor` posts the resolved source path to the dev server.
3. **Server:** the middleware resolves the path (`/relative` variant prepends `process.cwd()`) and spawns the editor named by `REACT_EDITOR`.
4. **Production:** component returns `null`; the middleware isn't registered; nothing ships.
