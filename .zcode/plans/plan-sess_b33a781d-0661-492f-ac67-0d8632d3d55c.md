# 需求 #3 后半部分实现方案：进程记录持久化 + 列表分页 + 过滤栏

## 背景
需求 #1（tanstack table + 未读 badge）、#2（stdout/stderr 合并）、#3 前半（日志搜索栏 grep）已完成。本方案完成 #3 剩余：
- 后端进程记录持久化保存（重启不丢）
- 查询接口返回已过期（停止/退出）的进程记录
- 进程列表分页 + 过滤栏

## 一、后端：lowdb 进程记录持久化

### 新增 `src/processes-repository.ts`（仿 logs-repository.ts）
- lowdb 文件：`<ServerDir>/processes.json`
- `ProcessRecord`（与 ProcessView 同构 + 时间戳）：
  ```ts
  { id, name, script, args, cwd, status, pid, exitCode, error,
    startedAt: number, stoppedAt: number | null }
  ```
- 接口：`initialize / upsert / getAll / getById / remove / close`
- `remove` 仅标记 stoppedAt，物理保留为历史记录

### 改 `process-manager.ts`
- 模块级 `processesRepository`，启动初始化
- `pushProcess` → upsert(startedAt=now)
- `applyProcessState` → upsert 同步 status/pid/exitCode/error
- `removeProcess` → upsert(stoppedAt=now, status 保持退出态)，保留记录
- 新增 `listProcessRecords()`：内存进程 ∪ lowdb 历史，去重（按 id）

### 改 `http-server.ts`
- `GET /api/processes` 改用 `listProcessRecords()`，返回含过期记录的合并视图
- 新增 `GET /api/meta` 返回 cwd（如未做则补）—— 已确认存在

## 二、前端：vendoring 组件 + 分页/过滤栏

### Vendoring coss 原语（当前缺失）
- `dashboard/src/registry/default/ui/select.tsx`（从 p-select-1 获取）
- `dashboard/src/registry/default/ui/pagination.tsx`（从 p-pagination-3 获取）

### 改 `ProcessList.tsx`
- 表头区加**过滤栏**：
  - 状态 `Select`：all / running / exited / error / spawning
  - 名称搜索 `Input`（前端即时过滤，非后端）
- tanstack 接入 `getPaginationRowModel()`（客户端分页）
- 表底加分页控件（p-table-4 模式）：`Select` 跳页 + Prev/Next + "Viewing X–Y of N"

### 改 `App.tsx`
- 无需改数据流（后端已返回含过期记录）

## 三、验收
- `tsc` + `vite build` 双绿
- 手动：启动进程→停止→重启后端→确认过期记录仍在、可按状态过滤、可分页翻页

## 设计决策（已默认选定）
- 过期记录靠 `stoppedAt!=null` + 既有 exited/error 状态区分，不新增状态枚举值
- 客户端分页（进程数量级小）
- 名称搜索前端即时过滤（区别于日志的后端 grep）
- restart 会更新同一条记录（id 复用，不产生新历史条目）
